### L1｜一家港股的 ESG 评级解读（旗舰内容，每月置顶）

**配图**：`02-listed-tencent.png`

```
腾讯的 MSCI 评级是 A。

很多人看到字母就结束了，但 A 到底说明什么？

我拆开讲：
· MSCI 共 7 档，A 是第 5 档
· 官方把 AA/AAA 归「领先」，A/BBB/BB 归「平均」，CCC/B 归「落后」
· 所以 A 是「平均组里最高的一档」，不是领先

再看分项：E 10、S 5.46、G 4.92（同一 0–10 分制）
环境接近满分，社会和治理在中段——三个维度成熟度并不平均。

这解释了为什么「拿 A」和「做得好」不能划等号：
不同机构选的议题、权重、行业组都不同，
甲机构的 A 和乙机构的 A，含义完全不一样。

对外引用时写全「MSCI A（评级日期）」，
别简写成「本公司获评 A 级」——被追问时容易失分。

我把 14 家机构的尺度、方向、差异整理成了对照表，
需要的话私信「评级」，发你一份。

#ESG #HKEX #可持续金融
```

```
同样一家公司，MSCI 给 A，商道融绿给 A，中债给 7 分。

不是谁错了，是尺子不同：
· MSCI：0–10 分，7 档，行业相对
· 标普：0–100，越高越好，无字母档
· 中债：1–10 整数分，债券视角

最容易被误读的两个：
1. 有机数的分越高越差，不是越好
2. D- 有时是「数据不可得」，不是「绩效最差」

所以别把不同机构的字母放一起排名。
正确的读法：同机构、同行业、看趋势和分项。

### L10｜「双重重要性」到底是什么意思？

**配图**：`04-rating-path.png` 或自制四象限图

```
ESG 报告里最常见的一个词：双重重要性。

拆开就两件事：
1. 财务重要性：这个议题会不会影响公司的收入、成本、风险
2. 影响重要性：公司的活动会不会影响环境和社会

两个都高 → 实质议题，必须重点披露
一个高一个低 → 看情况
两个都低 → 低优先

难点不在概念，在于「怎么打分才不失真」。

一个常见错误：把「绩效好」当成「不重要」。
某项做得好，不代表这个议题对公司不重要——
它可能恰恰是行业的核心风险。

所以打分要分开：
绩效是绩效，重要性是重要性。

#ESG #双重重要性 #可持续披露
```

### L11｜碳排放自己怎么算？范围一、范围二

**配图**：自制碳核算截图

```
不用等顾问，范围一和范围二自己就能算。

范围一（直接排放）：

范围三（食材供应链）复杂得多，建议先放一放。

（因子以最新官方公布为准）

## 六、表述红线（所有平台通用）

1. 不承诺评级结果、不说「保证升到 A」。
2. 不承诺补助获批、不说「包过」「一定拿得到」。
3. 不写未发生的客户名称与案例；演示数字标注「示例」。
4. 不把系统输出说成审计、鉴证或合规结论。
5. 补助金额、资格、可开支范围，一律加「以官方最新公布为准」。
6. 不夸大节省金额（如「省 30 万」），用可核实的对比（顾问费区间 8–30 万，来自公开市场行情）。
7. 不盗用第三方报告截图；引用公开数据要标来源。
