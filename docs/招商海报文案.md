## 三、从"有数据"到"有方向"（海报第二落点）

**标题**
> # 不只帮你填表，还告诉你先改哪一项

**三个要点**
- **对标行业基准**：领先 / 持平 / 落后，差距给到百分比，不再是"感觉还行"
- **改进动作分三档**：立刻能改 → 一年内 → 需要投入，按优先级排队
- **输出可直接用**：一份带章节结构、数据来源和改善建议的报告底稿

**小字**
> 例：某餐饮企业清洁能源占比 3%，行业 75 分位为 18%，差距 −15 个百分点 → 建议列入"一年内"改造项。

## 五·附｜V4 新功能（B 版可选加，A 版可作小字）

**三句话讲清新功能**

- **双重重要性评估**：一张四象限图，看清哪些议题对企业财务和环境影响都大，该优先披露哪个。
- **自动评分建议**：上传采集表后，系统按你与同行的差距自动推荐重要性评分，每条都写清依据，可以逐项改。
- **碳核算计算器**：输入燃气与用电量，按中电 / 港灯公开因子算出范围一、范围二排放与排放强度。

**小字（诚实边界）**
> 评分建议是「建议」不是定论：表现领先不代表议题不重要，系统不会因为某项做得好就把它降级；只有落后于同行才提示上调。
