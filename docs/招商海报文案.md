## 三、从"有数据"到"有方向"（海报第二落点）

**标题**
> # 不只帮你填表，还告诉你先改哪一项

**三个要点**
- **对标行业基准**：领先 / 持平 / 落后，差距给到百分比，不再是"感觉还行"
- **改进动作分三档**：立刻能改 → 一年内 → 需要投入，按优先级排队
- **输出可直接用**：一份带章节结构、数据来源和改善建议的报告底稿

**小字**
> 例：某餐饮企业清洁能源占比 3%，行业 75 分位为 18%，差距 −15 个百分点 → 建议列入"一年内"改造项。
