# ESG 智能報告系統 · 功能詳解

> 版本：V1（獲客版）｜更新日期：2026-11-20
> 適用對象：香港中小企、商會 / 行業協會、生產力促進局等機構
> 系統網址：https://esg-v1-0uyh.onrender.com

---

## 一、系統定位

一套面向香港市場的 ESG 數據與報告工具，解決三件事：

1. **上市公司**：不用逐個網站查評級、逐頁翻報告，一次查詢拿到多機構評級與報告核心數據。
2. **非上市公司**：不用各部門來回催表，一張採集表收齊數據，自動對標行業基準。
3. **兩類企業**：不只給數據，還給「差在哪、先改哪一項」的改善順序。

系統不替代顧問與核數師，定位是**把底稿做出來**：數據齊、口徑一致、來源可查，讓後續審閱與披露決策有依據。

## 二、上市公司模組

### 2.1 多源數據聚合（7 類數據源）

輸入港股代碼（如 `00700`）後，系統並行查詢 7 個來源，單一來源失敗不影響其他來源：

| 數據源 | 內容 | 說明 |
|---|---|---|
| Yahoo Finance | 公司資料、行業板塊、Sustainalytics ESG 評分 | 港股代碼自動規範為 4 位（`00700` → `0700.HK`） |
| 新浪財經 ESG | 多機構評級（實測覆蓋 14 家機構） | 含 MSCI、中證指數等，免 token |
| SBTi | 是否加入科學碳目標、近期 / 淨零目標年份 | 判斷減排目標是否主流 |
| 香港政府開放數據 | 香港溫室氣體排放與碳強度 | 行業與地區基準 |
| World Bank | 國家層面排放基準 | 跨地區對照 |
| NZDPU | 企業級排放披露 | 需配置 token，未配置時自動跳過 |
| 港交所披露 | ESG 報告元數據 | 搜索接口目前不穩定，建議直接提供 PDF 連結 |

**輸出**：公司概況、ESG 評分、SBTi 狀態、多機構評級表、香港行業基準，並在頁面標註哪些來源本次不可達。

### 2.2 上市公司評級指標怎樣看

多機構評級的作用是**集中呈現、保留口徑、交叉核對**，不是把不同機構的分數平均，也不是替企業生成一個「綜合評級」。系統頁面與報告保留機構、原始評級、評級日期及可用的 E / S / G 分項，並提供評級來源入口。

#### 2.2.1 E / S / G 分別代表甚麼

| 維度 | 主要內容 | 閱讀注意 |
|---|---|---|
| 環境 E | 能源與溫室氣體排放、水資源、廢棄物、污染物、氣候風險及環境管理 | 不同機構選用的議題、指標與行業權重不同 |
| 社會 S | 員工權益與安全、多元共融、培訓、供應鏈責任、產品質量、客戶私隱及社區影響 | 社會分項不是單看員工人數或公益投入 |
| 治理 G | 董事會結構與獨立性、商業道德、反貪污、風險管理、舉報機制、披露及股東權益 | 治理評價通常還會考慮爭議事件與問責機制 |

E / S / G 分項只在**同一家機構的評價體系內**解讀，不把甲機構的 E 分與乙機構的 E 分直接比較。空白分項表示來源未提供，不作零分或估算填補。

#### 2.2.2 先看「這個等級代表甚麼」

頁面在每個等級下方直接標出通俗位置（如 MSCI `A` → 同業中段），展開後先給一句人話結論，再給技術細節。閱讀順序是：

1. **它在尺度上的位置**：共幾檔、這是第幾檔，或 0–100 分中的哪個區間。
2. **機構的官方分組**：例如 MSCI 的領先／平均／落後，華證的固定分數線，有機數的風險帶。
3. **一句話含義**：管理處於同業中段、風險暴露較低，還是需要重點改善。
4. **E/S/G 分項**：哪個維度強、哪個維度弱。

以 MSCI 為例：`A` 是七檔中的第 5 檔，屬官方「平均」組，含義是「關鍵 ESG 議題已有基本管理，處於同業中間位置，但尚未形成領先優勢」。這樣才回答「拿了 A 到底說明甚麼」，而不是先講 IAS 和 WAKIS。

目前實測返回的 14 家機構，各自最關鍵的差異如下：

| 機構 | 尺度與方向 | 真正不同的地方 | 讀的時候要注意 |
|---|---|---|---|
| MSCI | IAS 0–10，分 CCC–AAA 七檔 | 按 GICS 子行業選 2–7 項 E/S 議題，治理 6 項全評並用扣分法 | 同行業相對風險管理，不是實際影響或道德評分 |
| 標普 | 0–100，越高越好，無字母檔 | 雙重重要性、62 套行業問卷、MSA 爭議扣分 | 不公布固定分數線，無同業分布難判高低 |
| 中證指數 | 原始 0–1，全樣本九等分 C–AAA，另有 D | V4.0 兼顧絕對與相對表現，關注事件 3–5 級可在單元層扣分 | D 是條件觸發，不是普通最低分 |
| 國證指數 | 10 檔 D–AAA | 220 餘項指標、行業中性、穿透關聯公司風險 | 未公布各檔分數線；未出等級可能是數據不完備 |
| 中國國新 | 九檔 AAA–C | 中國國新本土框架，3 範疇／122 項四級指標 | 官方查詢頁覆蓋 A 股，港股覆蓋需確認 |
| 中債 | **1–10 整數分**，不用字母 | 債券視角、缺失值統計補空、每月發布 | 不是債項或主體信用級別，別與 AAA 體系混排 |
| 商道融綠 | 0–100，十檔 A+ 至 D | 主動管理＋風險暴露、51 個行業模型 | 港股主要是曾納入港股通的公司，非全部港股 |
| 聯合赤道 | 七級 17 檔（含 +／-） | 評分→基礎級→負面事件調整→行業風險→最終級 | 用了信用風險數據，但不輸出償債信用級別 |
| 中誠信 | 七級 17 檔 | 治理權重最高：E 18.7–28.3%、S 24.1–34%、G 44–51.8% | 官方明確不評價信用狀況；最終級由評審委員會定 |
| 秩鼎 | 九檔，分領先／一般／落後三組 | 本土與行業特定指標（安全生產、汽車召回、藥品抽檢） | 分數閾值未公開，不能當跨機構絕對分 |
| 華證 | 0–100，**分數線公開**：AAA≥95、A 85–90、C<60 | 按三級行業影響程度與持續時間賦權，非核心議題可為 0 | 行業調整後偏相對表現，跨行業比較不合適 |
| 有機數 | 0–100 **風險分，越高越差** | 只採第三方記錄、25 類風險議題、日更 | 方向與多數評級相反；低分不代表績效優秀 |
| 妙盈 | 0–100 或十二檔 D–AAA | MICS 11 個一級、62 個二級行業，AI 另類數據 | 現行閾值未完整公開，需核對版本 |
| 中財綠金院 | 十二檔 A+ 至 D- | 31 個二級行業、E 加分扣分、本土議題 | D- 有時是數據不可得，不等於績效最差 |

**重要邊界**：部分機構的完整指標權重與評級模型並未公開。系統只解釋可確認的公開口徑，不根據單一指標反推評級，也不承諾改善某項指標後必定升級；機構更新方法後以最新公開文件為準。

#### 2.2.3 完整案例：騰訊（00700）的 MSCI A 到底說明甚麼

系統在評級表下方會用當前查詢到的真實數據自動生成一份解讀示例。以騰訊為例：

| 步驟 | 內容 |
|---|---|
| ① 結論 | MSCI 給騰訊 `A`，屬「同業中段」：關鍵 ESG 議題已有基本管理，處於同業中間位置，但尚未形成領先優勢。 |
| ② 位置 | MSCI 共 7 檔，`A` 是第 5 檔；官方把 AA／AAA 歸為「領先」、A／BBB／BB 歸為「平均」、CCC／B 歸為「落後」，所以 `A` 是平均組中最高的一檔。 |
| ③ 分項 | E 10、S 5.46、G 4.92（同一 0–10 分制，10 最好）：環境維度接近滿分，社會與治理處於中段，說明三者成熟度並不平均。分項權重不同，只作方向性參考。 |
| ④ 交叉對照 | Sustainalytics 未管理風險分若為 20–30（中等風險），與 MSCI `A` 並不矛盾：前者看「還剩多少未被管理的風險」，後者看「在同業中的管理能力」。 |
| ⑤ 怎麼用 | 對外引用要寫全「MSCI A（評級日期）」，不能簡寫成「本公司獲評 A 級」；客戶問卷可講環境管理的具體做法，社會與治理要準備改進措施，否則被追問時容易失分。 |

這個案例的價值在於把「字母」翻譯成三件事：**在同業中的位置、哪個維度強哪個維度弱、對外可以怎麼講**。它同時說明為甚麼不該把 MSCI `A` 和別家的 `A` 當成同一件事——有機數的 `A` 是「風險較低」（21–25 分），商道融綠的 `A` 是「同業領先」，含義完全不同。

#### 2.2.4 Yahoo / Sustainalytics 與 SBTi 不能當成一般字母評級

- **Yahoo / Sustainalytics ESG 風險分**：主要衡量企業未管理的 ESG 風險，通常是**分數越低、風險越小**。常見風險帶為 0–10 可忽略、10–20 低、20–30 中、30–40 高、40 以上嚴重；應與「越高越好」的表現評分分開閱讀。
- **SBTi 目標狀態**：表示企業是否承諾或設定科學碳目標，以及近期 / 淨零目標年份與覆蓋範圍。它是**減碳目標狀態，不是綜合 ESG 評級**，不參與字母等級排名。

#### 2.2.5 為甚麼同一家公司會有不同評級

不同機構的評估範圍、行業議題權重、數據年份、爭議事件處理與同行組別均可能不同，因此評級不一致是正常現象。系統不做簡單平均，建議按以下順序閱讀：

1. 先確認評級日期與企業代碼是否對應。
2. 再看該機構是評「表現」還是評「風險」。
3. 在相同機構、相同行業口徑下觀察趨勢與分項。
4. 回到企業原始 ESG 報告、公告及爭議事件核對原因。

**示例**：某公司獲 MSCI `AA`，但 Sustainalytics 風險分仍屬中等，兩者並不矛盾：前者可能反映其同業相對管理能力較好，後者提示仍存在需要管理的 ESG 風險。

「暫無公開評級」只表示機構未覆蓋、未公開或本次未取到，**不代表 0 分或評級差**；多家機構結果一致也不等於經過審計或鑑證。

### 2.3 港交所報告 PDF 抽取

在上市公司頁填入 ESG 報告 PDF 連結（例如港交所披露易的 PDF 地址），系統會：

1. 下載 PDF 並解析全文（支援繁體 / 簡體 / 英文報告）。
2. 按關鍵詞與數字密度篩選相關頁面，**附錄與 KPI 匯總頁優先**送入模型。
3. 抽取以下結構化數據：

| 類別 | 抽取欄位 |
|---|---|
| 溫室氣體 | 範圍一、範圍二（市場法 / 地區法）、範圍三總量與類別 1–15、排放強度、營運排放合計、較基準年減排比例與基準年 |
| 能源 | 總能耗、可再生能源佔比、能耗強度 |
| 水與廢棄物 | 取水量、水強度、有害廢棄物、無害廢棄物 |
| 員工 | 員工總數、女性比例、流失率、人均培訓時數、工傷死亡人數、損工事故率 |
| 治理 | 董事會人數、獨立董事比例、女性董事比例、是否設 ESG 委員會、是否與薪酬掛鉤 |

4. 每類數據附**原文摘錄**，可回溯核對；輸出抽取信心分數與備註（單位換算依據、缺失原因）。

**實測**：96 頁中文版報告（騰訊 2025）約 40 秒完成，抽取信心 0.95，數值欄位 35/36 已填。

### 2.4 上市公司報告生成

自動生成五章結構：

1. 一、公司概況與 ESG 評分
2. 二、溫室氣體排放（含排放表與香港基準對照）
3. 三、員工與社會
4. 四、公司治理
5. 五、數據質量與方法學說明

報告頭部標註綜合數據完整度、數據來源清單（含 PDF 文件名）；每章附主題插圖，正文為可下載的 Markdown。

## 三、非上市公司模組

### 3.1 一張採集表，覆蓋 82 項指標

下載標準 Excel 採集表，按部門分發填寫：

| 維度 | 指標數 | 範例 |
|---|---|---|
| 環境 E | 24 項 | 綜合能耗、清潔能源佔比、範圍一 / 二排放、取水量、廢棄物、環保處罰 |
| 社會 S | 24 項 | 員工總數、女性佔比、流失率、工傷、培訓時數、供應商 ESG 評估覆蓋率 |
| 治理 G | 16 項 | 董事會規模、獨董比例、反腐培訓覆蓋率、供應商行為準則覆蓋率 |
| 行業 | 18 項 | 按行業補充的實質性指標 |

填寫規則：
- 不確定的項目可留空，系統會標註「未填 / 不適用 / 暫無數據」。
- 部分指標可自動派生（如清潔能源佔比 = 清潔能源用量 ÷ 總能耗）。
- 單位在表內統一，避免各部門口徑不一。

### 3.2 上傳即生成診斷

上傳 `.xlsx`（10MB 以內）後，系統輸出：

- **填報完整度**：已填項數 / 應填項數，逐項列出缺什麼。
- **派生指標**：自動計算強度、佔比、比率類指標。
- **行業對標**：與香港同行業基準比較，標註「領先 / 持平 / 落後」及差距百分比。
- **改善路線圖**：按「立刻可改 / 一年內 / 需要投入」三檔排序，每項給出具體動作。

### 3.3 非上市報告結構

按「現狀 → 對標 → 差距 → 路線圖」四段生成，包含環境 / 社會 / 治理三張指標表、差距分析表與分檔建議，可直接用於管理層匯報與客戶問卷。

## 四、報告交付與閱讀體驗

- **文檔化排版**：深綠封面、章節編號、每章主題插圖，接近正式報告觀感。
- **試讀機制**：上市公司預設只展示第一章，其餘章節顯示標題並鎖定；非上市展示前兩章。用於獲客引流。
- **管理員完整版**：帶管理口令訪問時自動解鎖全部章節。
- **導出**：Markdown 與 JSON 兩種格式，便於二次編輯或導入其他系統。
- **中英雙語界面**：同一頁面切換中 / 英文。

---

## 五、數據可信度設計

1. **來源可查**：每類數據標註來源；PDF 抽取數值附原文摘錄與頁碼。
2. **口徑說明**：營運排放明確為範圍一 + 範圍二（市場法），範圍三另列，不混算。
3. **信心與完整度**：報告頭部顯示抽取信心與綜合完整度，避免「看起來很完整」的誤導。
4. **人工複核提示**：所有自動抽取結果均標註「需人工核對」；系統輸出定位為底稿。
5. **基準來源公開**：行業基準來自港交所上市公司披露、港府統計與世行數據，非自行估算。

## 七、技術架構

- **後端**：Python 3.14 + FastAPI，7 個數據源並行採集（線程池），單源失敗隔離。
- **PDF 解析**：pypdf 提取全文，關鍵詞 + 數字密度 + 附錄特徵三層篩選。
- **抽取模型**：OpenAI 兼容接口（預設 DeepSeek），temperature=0，JSON schema 校驗後落盤。
- **前端**：單文件 HTML / CSS / JS，無框架依賴，圖表插畫為內聯 SVG。
- **緩存**：聚合結果內存緩存 10 分鐘；PDF 與抽取結果落地緩存目錄。
- **部署**：Render 免費層，環境變量配置 `LLM_API_KEY`、`ADMIN_TOKEN`；本地 `python start.py` 直接運行。

## 八、使用流程

### 上市公司（約 1 分鐘）

1. 輸入港股代碼（可選填公司英文名、年度）。
2. 點「快速診斷」，查看評級與公開數據。
3. 如需要排放 / 能耗 / 員工數據，貼上 ESG 報告 PDF 連結。
4. 查看試讀報告，下載 Markdown 或留資索取完整版。

### 非上市公司（約 1 個下午）

## 九、當前限制（需如實說明）

1. **PDF 必須是文本版**：掃描件 / 圖片版無法提取，系統會明確報錯。
2. **港交所搜索接口不穩定**：目前建議直接提供 PDF 連結，不依賴自動檢索。
3. **抽取需 LLM 密鑰**：未配置 `LLM_API_KEY` 時，PDF 抽取不可用，其餘公開數據功能正常。
4. **免費部署限制**：Render 免費層閒置 15 分鐘休眠，首次訪問約 50 秒冷啟動；長報告抽取可能受請求時長限制。
5. **抽取結果需人工複核**：模型可能出現單位換算或分類偏差，報告中已標註。
6. **尚未包含**：碳核算引擎（範圍三完整測算）、氣候情景分析、PDF 正式排版導出、多用戶權限體系，均在 V2 規劃中。
